VMware Licensing Rate Card
Broadcom per-core annual pricing — rates reflect 20% discounted tier used in estimator
Edition Pricing
VMWARE EDITION LIST PRICE (PER CORE/YEAR) 25% DISCOUNTED RATE USED IN ESTIMATOR
VMware Cloud Foundation (VCF) $350 ✓ (applied when VMware = Yes)
VMware Cloud Foundation (VCF) is the standard edition applied whenever VMware is marked as applicable in Step 2.
VMware Live Recovery
VMWARE LIVE RECOVERY LIST PRICE (PER PROTECTED VM/YEAR) 20% DISCOUNTED RATE USED IN ESTIMATOR
VMware Live Recovery $300.00 ✓ (applied only when "VMware Applicable" is checked and a protection count is provided)
Discount range: 0% – 40% (20% used in estimator). Live Recovery cost = (# of Prod Servers Protected) × $240/year.
VMware Distributed Firewall (Per Physical Core Pricing)
VMWARE DISTRIBUTED FIREWALL LIST PRICE (PER PHYSICAL CORE/YEAR) 20% DISCOUNTED RATE USED IN ESTIMATOR
Distributed FW per Physical Core / Year $120.00 ✓ applied only when "VMware Applicable" is checked
Discount range: 15% – 35% (20% used in estimator). Distributed Firewall cost = (Cores to License from VCF sizing) × $96/year.
VMware Avi / NSX Load Balancer (Service Engine Pricing)
VMWARE AVI / NSX LOAD BALANCER LIST PRICE (PER SERVICE ENGINE CORE/YEAR) 30% DISCOUNTED RATE (AVI BASIC) USED IN ESTIMATOR
Avi Enterprise per Service Engine Core / Year $3,500.00 ✓ (applied only when "VMware Applicable" is checked and Peak Throughput is provided). Annual cost = SE Required × $2,450.
Sizing rule: 1 Service Engine handles up to 1.5 Gbps of peak throughput. Service Engines Required = ⌈ Peak Throughput (Gbps) ÷ 1.5 ⌉. Annual cost = SE Required × $2,450.
Host & Licensing Sizing Constants
vCPU to Physical Core Ratio 2.5 : 1
RAM Overcommit Ratio 0.7 : 1 (physical : virtual)
HA / Failover Headroom 0%
Physical Cores per Host 32 cores
RAM per Host 1,024 GB
VMware cores are licensed at the host level. The estimator rounds up to the nearest whole host using the ceiling function.
